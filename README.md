# Excel to WhatsApp Automation

Automate your WhatsApp messages directly from Excel! This Python script reads phone numbers and messages from an Excel sheet and sends them automatically via WhatsApp.

## 🚀 Features
- Read contacts and messages from Excel (.xlsx)
- Send WhatsApp messages automatically
- 10 seconds delay to avoid blocking
- Simple and easy to use

## 🛠️ Tech Used
- Python
- openpyxl (for Excel)
- pywhatkit (for WhatsApp)

## 📦 How to Use
1. Install requirements: `pip install openpyxl pywhatkit`
2. Create `contacts.xlsx` with Phone Number and Message columns
3. Run: `python main.py`
